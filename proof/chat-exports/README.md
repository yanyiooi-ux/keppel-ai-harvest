# chat-exports (local backup only)

Save CodeBuddy chat exports here: in CodeBuddy open **History** (top right of the chat panel), pick a chat, choose
**Export**. Name them `YYYY-MM-DD_what.json`.

Everything in this folder except this README is gitignored. An export is the raw chat: it includes the rules and
memories CodeBuddy was given and the contents of every file it read, so it is not safe to publish as is. Keep them as
a dated backup of our CodeBuddy use. If one is ever needed for the submission, a person reads it first and removes
anything private.
