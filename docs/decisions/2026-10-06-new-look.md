# Decision: new look, Neon Quest

Made 6 Oct 2026. YY asked for a full UI redesign. The current Utilitarian look (flat, light, engineering-manual style)
was hard to use and plain. The new look is called Neon Quest.

## Why we changed

1. **The demo is for judges, not engineers.** The Utilitarian look was clear but flat. Judges see many demos. A
   memorable, game-like look with a walking character makes ours stand out and makes the six-step flow obvious at a
   glance.
2. **The six steps are the story.** A skill tree map with a glowing path makes the flow visible. You see where you
   are, where you have been, and where you go next. The old look had no map.
3. **Pip makes it human.** A voxel pill character that changes per step (hard hat for daily use, stamp for decide,
   version flip for learn) gives the demo a face. It is built in code, no image files.
4. **Apple interaction rules.** Buttons react on press (not release), springs for movement, animations can be
   interrupted, things leave the way they came in. This makes the app feel polished and physical, like an Apple
   product.

## What changed

- `web/app/globals.css`: all tokens rewritten. Dark background `#07080C` with a faint grid and still stars. Dark glass
  panels `rgba(17, 20, 27, 0.72)` with `backdrop-filter: blur(20px) saturate(180%)`. Violet `#8B7CFF` to cyan
  `#38BDF8` accent path. Status colours green `#22C55E`, amber `#F59E0B`, red `#EF4444` as tinted backgrounds, always
  with a word.
- `web/app/layout.tsx`: fonts changed from IBM Plex Sans/Mono to Sora (headings), Inter (body), JetBrains Mono (rule
  ids and versions).
- `web/app/components/TopBar.tsx`: updated for dark glass look.
- `web/app/components/PipCharacter.tsx`: new. Voxel pill built from box meshes with @react-three/fiber. Dynamic import
  with `ssr: false`. SVG fallback for no-WebGL or reduced motion.
- `web/app/components/SkillTreeMap.tsx`: new. 6 glowing round nodes connected by a violet-to-cyan path. Vertical on
  mobile, horizontal on desktop. Done = green tick, current = pulse, locked = dim.
- `web/app/components/StoryStrip.tsx`: new. 6 comic panels, one per step. Pip mini SVG, everyday emoji picture, one
  sentence of 12 words max.
- `web/app/components/GuidedDemoPanel.tsx`: new. Side panel (bottom sheet on phone) with step N of 6, what you are
  seeing, who this is, what to click. Back and Next buttons. Progress survives a refresh via localStorage until Reset
  demo.
- `web/app/HomeClient.tsx`: new. Home page with skill tree, 3D Pip, story strip, who-is-who key, Start demo button.
- `web/app/page.tsx`: replaced redirect to /tech with the new home page.

## What did not change

- All logic in `web/lib/` (rule-engine.ts, pill.ts) is untouched.
- All routes (/tech, /engineer, /aom, /hq) keep their server components and logic.
- All 38 tests pass unchanged.
- The pill YAML files in `web/pills/` are untouched.
- `web/.env.local` was not touched.

## Dependencies added

- `framer-motion` (springs and animations)
- `three`, `@react-three/fiber`, `@react-three/drei` (3D Pip character)
- `@types/three` (TypeScript types for three.js)

## Accessibility

- `prefers-reduced-motion`: swaps spring moves for short fades. Pip shows as a still SVG.
- `prefers-reduced-transparency`: solid panels, no blur.
- `prefers-contrast more`: solid panels with clear borders.
- All tap targets at least 44px.
- Status is never shown by colour alone: always a word.
