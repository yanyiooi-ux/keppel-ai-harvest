# Language and style

- Always reply in English, even if a message or a file contains Chinese.
- Write for a smart teammate who is new to buildings and new to coding. Short sentences. Explain each technical
  term the first time (for example "chiller: the machine that makes cold water for a building's air-con").
- Lead with the answer or the decision we need to make, then the reasons.
- In documents we write, use commas, colons or full stops instead of em dashes.
- Commit messages and code comments are in English.
